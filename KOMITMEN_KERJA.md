6 komitmen Anda sebagai calon anggota tim (jam respons, cara berkomunikasi, aturan branch & review, definisi “selesai”, cara menyikapi perbedaan pendapat, kejujuran kontribusi)
6 komitmen menjadi anggota tim :
1. Merespon pesan di grup tim maksimal 2 jam pada hari kerja
2. Menggunakan WhatsApp untuk komunikasi harian dan Github untuk pengerjaan
3. Saya berkomitmen untuk tidak pernah melakukan push langsung ke branch utama (main atau master). Saya akan selalu membuat branch baru dari branch pengembangan dengan format penamaan yang rapi (misal: `feature/nama-fitur` ). Sebelum kode saya digabungkan (merge), saya akan mengajukan Pull Request (PR) dan meminta minimal satu anggota tim lain untuk melakukan code review guna memastikan kualitas kode.
4. Saya sepakat bahwa sebuah tugas tidak dikatakan "selesai" hanya karena kodenya sudah berjalan di komputer saya. Tugas dinyatakan selesai  jika memenuhi kriteria berikut:
   - Kode berhasil di compile tanpa error.
   - Kode telah lolos proses Code Review dan disetujui oleh rekan tim.
   - Fitur telah diuji secara lokal dan berfungsi sesuai dengan kebutuhan spesifikasi.
5. Jika terjadi perbedaan pendapat atau konflik teknis di dalam tim, saya berkomitmen untuk menyikapinya secara kepala dingin dan objektif.
6. Saya berkomitmen untuk berkontribusi atas segala pekerjaan saya dengan sejujur jujurnya.
