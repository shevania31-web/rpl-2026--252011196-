Haloo inilah aturan sederhana untuk pengembangan projek :
1. Aturan Membuat Branch
Jangan langsung mengubah kode di branch "main". Buatlah branch baru sebelum mulai bekerja dengan format:
  - feat-nama-fitur` (untuk menambah fitur baru, contoh: "feat-halaman-login")
  - fix-nama-bug` (untuk memperbaiki eror, contoh: "fix-tombol-error")
  - docs-nama-dokumen` (untuk mengubah dokumen/tulisan, contoh: "docs-tambah-lisensi")

2. Format Pesan Commit
Tulis pesan commit dengan jelas dan singkat agar tim lain tahu apa yang kamu ubah. Gunakan format "<jenis-perubahan>: <penjelasan>".
Contoh:
  - docs: menambah panduan kontribusi`
  - feat: membuat halaman utama`
  - fix: memperbaiki link yang rusak`

3. Cara Mengajukan Pull Request (PR)
Jika tugas kamu sudah selesai dan ingin digabungkan ke branch "main", ikuti langkah ini:
  - Pastikan kode kamu tidak eror saat dijalankan.
  - Lakukan Push branch kamu ke GitHub.
  - Buka halaman GitHub, lalu klik tombol New Pull Request.
  - Tulis penjelasan singkat tentang apa saja yang kamu ubah.
  - Tunggu pemilik repository memeriksa dan menyetujui (approve) PR kamu sebelum di-merge.
